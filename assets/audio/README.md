# Audio asset slots

Place real audio files in these paths. The runtime already references them and fails silently when a file is missing.

- `ui/click.ogg`
- `ui/battle_start.ogg`
- `combat/hit_light.ogg`
- `combat/hit_heavy.ogg`
- `combat/critical.ogg`
- `bgm/battle.mp3`
- `bgm/selection.mp3`

Recommended: normalize SFX loudness before export and keep BGM loopable.
